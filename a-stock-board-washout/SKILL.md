# A股首板洗盘选股器（a-stock-board-washout）

> 分析**最近一个结束交易日 T**，输出一份深色「金融数据终端」风 Markdown 选股报告（红涨绿跌、结论前置、卡片化、内联 SVG 图表，免外链）。内置两条**首板洗盘**战法，各精选 3 只并给出第二日操作建议。

## 能力说明

- **策略一 · 首板后放量洗盘**：上一交易日 T0 首次涨停（`lbc==1`）、本交易日 T 未涨停，且**非科创板(688/689)/非创业板(300/301)**=仅主板(600/601/603/605/000/001/002)。结合 T 日分时回踩形态、量能放大、热点题材、主力资金、位置所处，筛选「首板次日放量洗盘」质量最高者 → 推荐 3 只 + 第二日操作建议。
- **策略二 · 炸板洗盘**：本交易日 T 涨停炸板、**非科创板/创业板**。优先保留「首板炸板」，结合 T 日分时炸板时段、量能、热点/资金/位置，识别「炸板但强势、次日可低吸」标的 → 推荐 3 只 + 第二日操作建议。
- **硬性质量门槛（质量闸门，两策略共用）**：流通市值 **≥50 亿**（100~300 亿最佳）、换手率 **≥5%**、成交额 **≥5 亿**、且**非高位（从底部起来）**。量比门槛**随市值自适应放宽**：小盘(<50亿)≥2.0、中大盘(100~300亿)≥1.5、超大票(300亿+，大市值天然放量比低、以大票成交量为主判据)≥1.2。全过才入「精选」；量比/门槛略差但洗盘意图极强的进入「邻近达标」观察栏（透明标注差项）。每卡用 4 枚达标徽章（✓金/✗绿）展示四维通过状态。
- **强洗盘意图分析（分时+量能，`_washout_qual`）**：四维综合打分——①放量(vq：量比+换手) ②分时承接(hq：收盘站上全天均价/VWAP) ③强意图(iq：盘中触涨停) ④收在高位(rq：距日高回吐小)。位置维度已从洗盘因子**剥离**（否则与"趋势/位置安全"因子对"回撤"三重计数），改由独立「位置安全」因子承载。质量高者加权后作为`强洗盘强度`展示并主导排名。
- **分时强弱洗盘定级（`wash_signals`，报告"综合判定"与操作建议/评分共用）**：**强信号**(0~3)：站上均价距均价为正、炸板不破位收高位、抛压轻(缩量回踩或温和换手不破均线)；**弱信号**(0~3)：下砸后整日在分时黄线(均价线)下方且收于其下、收盘在水下、拉升无量(低点回升量占比低未收复均价)。综合**强洗盘/温和洗盘/洗盘偏弱·防出货**，并配文字理由（量能分布/炸板缩量/尾盘质量）。弱势洗盘一律降级为"谨慎"、评分扣 10。
- **资金维度（主力资金，`fund_score`）**：主力净流入去规模为「占成交额% = `fund_ratio`」作评分因子（抵抗大小盘偏差、避免与流动性因子共线）。资金口径**统一走新浪逐股** `MoneyFlow.ssl_qsfx_zjlrqs`（netamount 主力净流入元 · ratioamount 净占比，0.2s 稳定不封），两策略跨策略可比、口径一致；**不保留池 `fund_yi` 兜底**。失败返回 {} 记 0 绝不阻塞；资金因子覆盖不足时降权自动让位（见下）。报告卡片展示「净流入金额 + 占成交比例 + 来源(新浪)」。
- **趋势维度（`trend_analysis`，纯K线无外联）**：综合**均线多头排列强度、MACD（金叉/死叉/水上）、RSI14（超买/超卖/健康）、量能趋势**（5日/20日均量比）→ `trend` 分(0~100)+标签（多头上升 / 低位启动 / 底部金叉 / 超跌企稳 / 平台整理 / 空头下行 / 高位偏风险）。上升趋势加分、空头/高位减分；趋势分<45 或标为"空头下行/高位偏风险"→ 操作建议降级**谨慎**。报告卡片新增「趋势」徽章与均线/MACD/量能/RSI 说明行。
- **多因子横截面评分模型**：六因子——洗盘强度(分时)/趋势(均线·MACD·RSI·量能)/资金(净流入占比)/低波动(20 日收益标准差反向)/位置安全(距 250 日高回撤)/流动性(成交额)，候选池内**横截面分位标准化(0~100)**，按策略差异化权重（S1 重趋势与位置，S2 重洗盘与资金）合成总分 0~100。稳健化四件套：**MAD 去极值**（单只离群不主导分位）、**均秩分位**（并列值同分）、**小样本向中性收缩**（2~3 只池不打出 100/0 假分）、**缺失记中性 50 不惩罚**；权重和自动校验=1。
- **因子覆盖度自适应降权**：某因子有效样本不足（<2 只 或 占比<20%，如炸板池资金 90% 缺失）则**自动让位、权重按比例重分配给其余因子**，防止噪声因子硬占权重；报告"模型·因子权重"栏灰显落马因子，卡片"量化因子分解"逐因子展示原始值/分位/权重/贡献。
- 每只候选渲染：**日 K 线蜡烛图**（含 MA5/10/20）+ **量能曲线**（量柱）+ **当日分时图**（价格线/均价线VWAP/量柱，策略二标注涨停价/昨收/炸板回落段），全部由 Python 生成**内联 SVG**，自包含无外链。
- 输出：`首板炸板洗盘-{YYYY-MM-DD}.md`（Markdown 报告，落在当前会话根目录 cwd）。报告结构：概览 → 策略一/二精选（各含**完整第二日操作建议**：结论·操作方式·触发条件·目标位·止损位·仓位）→ 备选池（第4~6名，附简要操作建议）→ 邻近达标观察（附操作建议 tag）。

## 使用流程

推荐一步到位（全流程：采集 → 筛选 → 出图），默认最近结束交易日：

```bash
cd <本技能目录>
python scripts/all.py                 # 全部流程（采集池/个股→筛选评分→渲染报告）
python scripts/all.py --date 20260825 # 指定交易日 T 覆盖
python scripts/all.py --no-report     # 只采集+筛选，不出图
```

分步（可选）：

```bash
python scripts/collect_pools.py                  # 拉 T0、T 的涨停/炸板/跌停池 + 涨停原因 -> data/pools_{T}.json
python scripts/collect_stocks.py                 # 每候选：腾讯日K + 当日分时 -> data/stocks_{T}.json
python scripts/screen_washout.py                 # 两策略筛选评分 + 操作建议 -> data/screen_{T}.json
python scripts/generate_report.py                # 渲染 Markdown 报告 -> {cwd}/首板炸板洗盘-{T}.md
```

> **「最近结束交易日」判定**：默认从今日起，若非交易日（周六/周日）回退到周五；再用「当日涨停池 total 非空」校验，空则回溯到最近有涨停池的日期（兜底 ~12 天）。上一交易日 T0 = 从 T 回溯到最近有涨停池的日期（自动跳过周末/节假日）。`--date YYYYMMDD` 可覆盖 T。

## 数据源

| 数据 | 来源 | 说明 |
|------|------|------|
| 涨停/炸板/跌停池 | 东财 `push2ex.eastmoney.com` `getTopicZTPool/ZBPool/DTPool`，`date=YYYYMMDD` | 字段含 code/name/price/chg/amount_yi/lbc/zbc/fund_yi(主力)/hs/hybk/fbt/lbt |
| 个股日 K 线（前复权） | 腾讯 `web.ifzq.gtimg.cn/.../fqkline/get` | 行 `[date,open,close,high,low,volume,...]`，volume 即量能 |
| 当日分时图 | 腾讯 `web.ifzq.gtimg.cn/appstock/app/minute/query` | 分钟价/量，失败则优雅降级为仅 K线 |
| 涨停原因（热点） | 同花顺 `zx.10jqka.com.cn/event/api/getharden`（GBK） | code→reason 映射，策略/题材标注 |

## 坑点

- 东财池可能遇 429/IP 风控：采集失败沿用旧文件（`dump_json_guard`），关键池缺失 exit 1 并提示换网络后重跑。
- 资金信号源已统一为新浪 `MoneyFlow.ssl_qsfx_zjlrqs`（东财 `fflow` 逐股接口易被风控已弃用；**不再回退池 `fund_yi` 口径**）：新浪缺数据时该票资金因子记中性、覆盖度降权让位，不阻塞主流程，不回填伪造数据。
- 腾讯分时接口异常不影响报告：该卡降级为「分时数据暂缺」，K线/量能照常出。
- 候选过少时不强行凑数：策略章节提示「候选不足」并展示现有候选。
