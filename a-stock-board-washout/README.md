# A股首板洗盘选股器（a-stock-board-washout）

分析**最近一个结束交易日 T**，输出深色「金融数据终端」风 Markdown 选股报告（红涨绿跌、结论前置、卡片化、内联 SVG K线/量能/分时图，免外链）。内置两条「首板洗盘」战法，各精选 3 只并给出完整第二日操作建议。

## 核心策略

| 策略 | 规则 | 说明 |
| --- | --- | --- |
| 策略一 · 首板后放量洗盘 | T0 首次涨停（`lbc==1`）且 T 日未涨停，仅主板 | 结合分时回踩、量能放大、热点、资金、位置，筛「首板次日放量洗盘」质量最高者 |
| 策略二 · 炸板洗盘 | T 日涨停炸板，仅主板 | 识别「炸板但强势、次日可低吸」标的；**宁缺毋滥**：硬门槛不过不进精选、不足 3 只不凑数 |

两策略共用的**硬性质量门槛**：流通市值 ≥50 亿（100~300 亿最佳）、换手率 ≥5%、成交额 ≥5 亿、非高位；量比门槛随市值自适应放宽（<50 亿→2.0、100~300 亿→1.5、300 亿+→1.2）。

## 评分模型

六因子在候选池内做**横截面分位标准化（0~100）**后加权合成总分，权重经 90 日大样本回溯实证：

| 因子 | 方向 | S1 权重 | S2 权重 | 含义 |
| --- | --- | --- | --- | --- |
| 波动 `vol` | 低好 | 26% | 28% | 20 日收益标准差，越低越稳 |
| 流动性 `liq` | 高好 | 28% | 29% | 成交额（亿） |
| 洗盘强度 `washout` | 高好 | 18% | 20% | 分时承接+触板+收高+放量 |
| 趋势 `trend` | 高好 | 10% | 8% | 均线/MACD/RSI/量能 |
| 资金 `fund` | 高好 | 10% | 10% | 主力净流入占成交额% |
| 位置安全 `pos` | 低好 | 8% | 5% | 距 250 日高回撤，越小越强 |

稳健化：MAD 去极值、均秩分位（并列同分）、小样本向中性收缩、缺失记中性 50；权重和自动校验 =1；`|fund_ratio|>100%` 物理不可能记中性（`FUND_RATIO_CAP`）。某因子有效样本不足（<2 只或占比<20%）自动降权让位，防止噪声因子硬占权重。

## 目录结构

```
a-stock-board-washout/
├── SKILL.md                    # 技能元数据与完整说明
├── README.md                   # 本文件
└── scripts/
    ├── _common.py              # 路径解析 / JSON 读写 / 因子常量 / 交易日
    ├── all.py                  # 全流程编排（含自学习闭环）
    ├── collect_pools.py        # 采集涨停/炸板/跌停池 + 涨停原因
    ├── collect_stocks.py       # 采集个股日K + 分时 + 行情 + 资金
    ├── screen_washout.py       # 两策略筛选 + 六因子评分 + 操作建议
    ├── generate_report.py      # 渲染 Markdown 报告（内联 SVG）
    ├── verify.py               # 回填历史推荐 T+1~T+3 表现
    └── evolve.py               # 自学习：反推六因子权重
```

## 快速开始

```bash
cd <本技能目录>
python scripts/all.py                 # 全部流程（采集→筛选→出图→验证→自学习）
python scripts/all.py --date 20260825 # 指定交易日 T
python scripts/all.py --no-report     # 只采集+筛选，不出图（仍跑自学习闭环）
python scripts/all.py --no-selflearn  # 出报告但跳过盘后验证+自学习
```

环境变量（均可选，脚本经 `_common.data_path()` 统一解析）：

| 变量 | 缺省 | 作用 |
| --- | --- | --- |
| `WASHOUT_ROOT` | `cwd` | 会话工程根目录，报告与过程数据的共同锚点（cwd 落在技能目录内时自动回退技能库父目录） |
| `WASHOUT_DATA` | `<ROOT>/a-stock-board-washout` | 过程数据根目录（采集缓存/筛选结果/验证样本/自学习权重） |
| `WASHOUT_OUT` | `<ROOT>` | 报告输出目录 |

过程数据**全部外置**、不落技能安装目录；报告输出到会话工程根目录。

## 自学习闭环

每次盘后运行 `all.py` 自动串联：

1. `verify.py` 用实际 K 线回填历史推荐 T+1/T+2/T+3 表现，累计 `verify_history.csv`（含 `hit` 与 T+1 可交易口径 `hit_t1`）。
2. `evolve.py` 对六因子做 Spearman 秩相关，方向正确放大、方向错误削弱，EMA 平滑后回写 `params_best.json`。
3. `screen_washout.py` 启动时读 `params_best.json` 覆盖先验权重并精确归一化（缺省回落先验）。样本不足（<30）维持先验不强行调参。
