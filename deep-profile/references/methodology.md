# 方法论详版（deep-profile 执行参考）

本文件是 `deep-profile` 深度挖掘阶段的完整方法论，供 LLM 在「公开扩展 → 交叉验证 → 深度挖掘 → 画像生成」各阶段引用。目标是让画像**连得准、信得过、挖得深**，而非标签堆砌。

---

## 一、八维数据源矩阵

| 维度 | 数据类型 | 典型来源 | 技术手段（LLM 执行映射） |
|---|---|---|---|
| ① 公开数字足迹 | 社交内容、新闻、博客、公开视频字幕 | 微博/知乎/小红书/B站/领英/X/GitHub、搜索引擎、新闻媒体 | 多引擎并行 `WebSearch` + 组合搜索语法 + 视频字幕转写 |
| ② 半公开结构化 | 工商、司法、知识产权、学术、招聘、开源 | 天眼查/企查查/裁判文书网/专利库/ORCID/GitHub | `WebFetch` 结构化页面 + 图谱映射 |
| ③ 用户授权数据 | 邮箱收件箱、聊天导出、CRM、本地文档 | 用户上传、OAuth2.0、IMAP、本地文件 | 事实抽取 + 独立向量库隔离（标注来源） |
| ④ 设备与行为信号 | 浏览历史、APP 使用、搜索词 | 用户侧本地 Agent | 本地特征提取，仅上传脱敏特征 |
| ⑤ 多模态生物信号 | 演讲视频、会议照片、微表情/语速 | YouTube/B站/公开直播 | 描述性分析（姿态/语速/情绪），输出为线索 |
| ⑥ 知识图谱补全 | 通用/行业知识、政策法规 | Wikidata/DBpedia/UMLS/政策库 | 背景知识补全，不作为硬证据 |
| ⑦ 域名/IP/资产暴露面 | 域名、IP、子域名、端口、证书 | WHOIS/DNS/证书透明日志/Shodan/Fofa/ZoomEye | 资产测绘（公司画像重点） |
| ⑧ 威胁情报/暗网 | 泄露库比对、黑市交易、钓鱼样本 | 威胁情报平台 | 哈希比对、泄露影响评估（标注风险） |

**执行原则**：
1. 公开数据优先，授权数据仅在用户明确提供后使用并标注来源。
2. 跨源关联统一使用**不可逆哈希标识符**（如 `SHA-256(email+salt)`）作为节点，salt 本地生成。
3. 维度 ③④⑤⑧ 多为受限/敏感源，落到报告中必须标注置信度与合法合规边界，不可默认视为已获得。

## 二、七阶解构法（定性深度）

| 阶段 | 解决的问题 | 核心方法 | 输出示例 |
|---|---|---|---|
| 1 基础锚定 | 是谁 | 全字段身份核验 + 政务/学术/GitHub 交叉比对 | 唯一 ID、姓名变体、脱敏地域 |
| 2 社会面具测绘 | 如何被世界使用 | 高频动词提取 → 决策风格；互动统计 → 影响力半径 | 「危机稳定器」型管理者 |
| 3 核心矛盾挖掘 | 什么让其与众不同 | 兴趣悖论 / 行为张力 / 价值观冲突 TF-IDF 反差 | 「技术极客 vs 文艺哲思」 |
| 4 底层驱动溯源 | 什么暗中推动 | 恐惧层/欲望层/使命层三层驱动建模 | 「对技术失控的深层恐惧」 |
| 5 关系网络拓扑 | 嵌入何种生态 | 显性(股权/协作) + 隐性(思想同盟) + 对抗关系 | 影响者图谱 |
| 6 时空行为建模 | 如何随环境演化 | 能力进化曲线 + 认知疆域地图 + 突变检测 | 技能迁移路径 |
| 7 留白与推演 | 下一步做什么 | 未竟之志预测 + 未来内容生成 | 3 种可行路径概率 |

**落地映射（LLM 可执行）**：
- 阶段 2「高频动词」= 对采集文本做动词词频统计与语境归纳（如「主导/推动/协调」→ 结果导向；「倾听/共识/尊重」→ 关系导向）。
- 阶段 3「TF-IDF 反差」= 对比不同场域（技术文 vs 社论 vs 私人随笔）的高频词差异，定位身份张力。
- 阶段 4「三层驱动」= 从回避话题（恐惧）、反复追逐目标（欲望）、公开表态的价值主张（使命）反推。
- 阶段 6「突变检测」= 对比时间线相邻阶段的行为模式跳变（如突然从技术岗转向管理/公益），标注突变点并追因。

## 三、五阶穿透式推理框架（置信度量化）

| 阶段 | 目标 | 方法论 | 输出 |
|---|---|---|---|
| L1 原子事实层 | 校验基础属性真实性 | 多源交叉验证 | 置信度 98.2% 的基础身份 |
| L2 行为模式层 | 发现稳定行为规律 | 时序聚类 + 周期分解 + 异常检测 | 作息与消费规律 |
| L3 意图推断层 | 解析行为背后动机 | LLM 意图推理 + 因果发现 | 正在筹备某事（证据链） |
| L4 关系拓扑层 | 揭示隐性社会连接 | 图嵌入 + 社区发现 + 影响传播 | 核心节点、扩散层级 |
| L5 数字孪生层 | 构建可交互仿真体 | 行为预测 + 反事实推演 | 「若改变 X，将如何」 |

**落地映射（LLM 可执行，不训练真实模型）**：
- L1 = 多源一致即高置信；单源/推断降级。
- L2 = 从公开时间线提取「稳定的作息/发布/消费/出行」规律，异常即标记。
- L3 = 综合近 3–6 个月的密集动作（连续发文、频繁会面、注册商标、招聘扩编）推断动机并列出证据链。
- L4 = 关系共现分析（同一活动/项目/公司/社群反复出现的人与机构）。
- L5 = 反事实 What-if：改变某个变量（资金、职位、合作伙伴）推演 3 条概率路径。

## 四、关系拓扑

| 关系类型 | 判定依据 | 报告呈现 |
|---|---|---|
| 显性关系 | 股权、任职、合作、家庭成员、同学 | 实线 |
| 隐性关系 | 思想同盟、共同社群、同频发言、互推 | 虚线 |
| 对抗关系 | 诉讼、竞争、公开争议、观点对立 | 红色 |

**落地映射**：从共现、利益、立场三个维度给关系定性：
- 共现：是否反复出现在同一时空/项目/组织。
- 利益：是否存在股权/交易/雇佣等可量化利益纽带。
- 立场：公开观点是否同向或对立。

## 五、数字孪生四层 + 推演

| 层 | 含义 | 报告映射 |
|---|---|---|
| 静态锚点层 | 唯一强标识为根节点的身份骨架 | 基础身份锚定 |
| 动态行为层 | 时序意图流 | 时空行为建模 |
| 语义理解层 | 「兴趣—动机—价值观」语义向量 | 核心矛盾 / 底层驱动 |
| 关系网络层 | 社交圈层/供应链/知识协作 | 关系网络拓扑 |

**未竟之志预测**：基于 SOUL 主文件中的未完成事项 + 资源匹配度，生成路径概率（3 条）。
**反事实 What-if**：把 Neural ODE / GAN 的概念映射为 LLM 路径推演——「若改变 X（职位/资金/合作/监管），目标最可能转向哪条路径」，输出概率与依据。

## 六、社会面具 — 核心矛盾 — 底层驱动（逻辑骨架）

深度画像不是「列标签」，而是回答三层问题：

1. **社会面具**：他如何被世界「使用」（职位、头衔、公众角色、他人对他的期待）。
2. **核心矛盾**：他「内在张力」是什么（兴趣悖论、价值观冲突、行为反差），这是区别于同类的独特性。
3. **底层驱动**：真正「推动他」的是什么（恐惧/欲望/使命三层），这是预测未来行为的钥匙。

> 三者构成一句话灵魂定义（SOUL）：「一个以【社会面具】示人、被【核心矛盾】拉扯、最终被【底层驱动】推动的人/组织」。
