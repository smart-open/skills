# 设计系统（deep-profile 内置，蒸馏版）

本文件是 deep-profile 报告的**自包含设计规范**（蒸馏自 frontend-design，聚焦本技能「情报档案」场景），不再依赖任何外部设计技能。具体 CSS 实现见 `html-template.md`，本文件定义其背后的设计决策与质检标准。

---

## 一、设计立场（先定调，再写码）

每份画像报告动手前先回答四问，并保持全篇一致：

1. **目的**：这是一份可审计的深度身份档案，读者是决策者（尽调/风控/谈判准备）。
2. **调性**：**情报档案（dossier）气质** — 墨黑底、金琥珀强调、衬线标题传递权威感、mono 传递证据感。克制、精密、可信任。
3. **约束**：单个自包含 HTML；`file://` 可开；中文阅读为主。
4. **记忆点**：结论前置摘要 + 置信度徽章贯穿全篇 — 「每个结论都标着证据等级的档案」。

> 大胆与克制都成立，关键是有意图。本报告的意图 = **权威 + 可审计**，一切选择为其服务。

---

## 二、字体排印

- **三轨字体**：标题衬线（`Noto Serif SC`）传权威；正文无衬线（`Noto Sans SC`）；技术标签/日期/来源用 mono（`JetBrains Mono`）传证据感。
- **禁用** Inter / Roboto / Arial / 系统默认作为**身份字体**（可作回退栈）；禁止每次生成都收敛到同一「网红字体」。
- Google Fonts `<link>` + 系统栈回退（`PingFang SC` / `Microsoft YaHei` / `Songti SC`），离线优雅降级。
- 标题 `text-wrap: balance`；章节编号（如 `IDENTITY` / `NETWORK`）用 mono 小写字距（`letter-spacing: .12em`）小标签，营造卷宗感。

## 三、色彩

- **一套 CSS 变量统治全篇**：暗色分层底（`#0d0e12 / #15171d / #1c1f27`）承载 95% 的面积，**单一金琥珀 `#d4a24e`** 作锋利强调（章节下划线、核心节点、里程碑、卡片顶边）。
- **语义色仅按固定映射使用，不作装饰**：

| 语义 | 色 | 仅用于 |
|---|---|---|
| 强调 | `#d4a24e` | 章节锚点 / 核心节点 / 悬停 |
| 危险 | `#e05656` | 风险卡 / 对抗关系 / 突变点 |
| 置信 A | `#4ade80` | 置信度徽章 |
| 置信 B | `#5b9bd5` | 置信度徽章 / 隐性关系 |
| 置信 C | `#d4a24e` | 置信度徽章 |
| 置信 D | `#8a8a94` | 置信度徽章 |

- **禁止**：白底紫渐变、彩虹配色、每种卡片一种颜色的「调色盘式」设计。

## 四、动效（CSS-only，服务阅读）

- **一次编排好的入场**：摘要卡进入视口时 `animation-delay` 交错浮现（staggered reveal），比散落的小动效更高级。
- 高影响时刻优先：Hero 渐显 → 摘要卡交错 → 章节滚动锚点高亮 → 阅读进度条 → 回到顶部。
- hover 用 `translateY(-3px)` + 边框变强调色 + 轻微阴影提升；不用磁吸按钮、不用全篇玻璃拟态。
- 所有非必要动画包 `@media (prefers-reduced-motion: reduce)` 降级。

## 五、空间构成

- **不对称 Hero**：左对齐 kicker + 大标题 + 灵魂定义，右侧留出负空间，**不做**居中三段式堆叠。
- **密度分区**：摘要区疏朗（大卡 + 负空间）；身份表格区高密度（数据行）；证据区中密度带竖向层级。档案的可读性来自「疏密对比」而非均匀铺排。
- **网格破格点缀**：卡片顶边 3px 强调线、证据项左侧置信色竖线、风险卡红左边 — 用最小代价建立视觉层级。
- Hero 背景用**单一径向光晕**（radial-gradient）营造深度，不堆叠噪点/网格/多层光效。

## 六、背景与细节

- 深度来自**分层卡片 + 边框色阶**（bg → bg-2 → bg-3），不依赖阴影堆叠。
- 图表容器（`.chart`）统一 `#0f0f1a` 更深一档的底色，与内容卡形成「嵌入屏幕」感。
- 虚线边框（`.gap` 卡）专用于「未确定/缺口」语义 — 形式跟随语义。

## 七、反 AI 俗套（不可协商）

1. **禁 emoji 图标**（不用 ✅❌🎉；勾选用 SVG/文字，风险用色彩与文案表达）。
2. **禁紫蓝渐变**作为默认审美。
3. **单一强调色**贯穿全篇；中性色承载其余。
4. **统一圆角体系**（sm 8 / md 12 / lg 16），不混用 4px 与 24px。
5. **无空卡片**：N 项内容 N 个格子，不足 3 项就删掉网格。
6. **无重复 CTA / 无装饰性圆点 / 无横向滚动条**（表格除外，容器内滚动）。
7. 可见文本**不用长破折号**（em/en dash），中文标点用「」与顿号。
8. **具体数字胜过模糊宣称**：「3 个独立来源交叉验证」而非「多方验证」。
9. 每次生成的报告**不得互相雷同**：在保持档案气质的前提下，按目标特征微调（行业色温、章节侧重、图表密度）。

## 八、设计质检（交付前过一遍）

- [ ] 三轨字体齐备，mono 只用于证据性标签
- [ ] 全篇只有一个强调色，语义色严格按映射表使用
- [ ] Hero 不对称，摘要卡有交错入场动效
- [ ] 置信度徽章在字段表 / 风险卡 / 证据链三处样式一致
- [ ] 疏密分区明显，无均匀铺排感
- [ ] 0 个 emoji、0 个空卡片、0 处紫蓝渐变
- [ ] `prefers-reduced-motion` 降级生效
- [ ] `file://` 打开时字体回退后依然成立（层次不靠字体撑）
