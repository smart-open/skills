# 爆款叙事结构库（framework.md）

> 写简稿时必须显式声明所用的框架（framework 字段），并在稿末回环。三个框架可复合，
> 但单篇简稿（200–400 字）以一个主框架为宜。

## F1 铺垫—反转—回环（Callback 三段式）

- **结构**：开场抛出一个大众共鸣情境（10%）→ 按常识铺垫预期（40%）→ 预期违背抛出反转（30%）
  → 用反转里的关键词回环收尾/召唤开场情境（20%）。
- **要点**：回环词必须在铺垫段自然出现过一次（观众当时没意识到），反转后才恍然大悟。
- **适用**：职场、家庭、消费、社交场景；最稳的通用结构。
- **结束钩**：最后一句用回环词收，不解释、不总结。

## F2 递进吐槽（三连击排比）

- **结构**：锁定一个吐槽对象 → 三连击，一句比一句狠（每击都要有新信息，不许同义反复）
  → 最后一击打回自己（自嘲收尾），完成"损人→损己"的落地。
- **要点**：三连击之间用递进词（"更离谱的是""你以为这就完了"）保持势能；
  第三击必须比第二击剂量大一级。
- **适用**：现象吐槽（房价/加班/催婚/APP 会员）；情绪外向型段子。
- **结束钩**：自嘲句 + 停顿，让"笑声落点"自己出现。

## F3 故事嵌套（"我朋友"就是我自己）

- **结构**：以第三人称讲"我朋友/我同事"的离谱故事（70%）→ 细节越讲越具体、
  越讲越像亲历（15%）→ 结尾揭底"那个朋友就是我"（15%）。
- **要点**：铺垫段埋 2 个只可能发生在自己身上的细节（观众回看才发现）；
  揭底句要短（≤10 字），揭底后立刻补一个自嘲，不留说教。
- **适用**：相亲、借钱、社死现场等需要"安全距离"的尴尬题材。
- **结束钩**：揭底 + 自嘲连招。

## 节奏通用规则

- 单镜 ≤12s（视频模型上限），笑点（预期违背）不允许跨镜。
- 每 40 字左右一个"信息增量或情绪转折"，全文至少 3 个笑点、1 个共鸣点。
- 结尾必须落在停顿点（"说完自然停顿"），方便转场拼接。
