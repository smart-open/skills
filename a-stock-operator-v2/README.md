# A股行情复盘与个股诊断生成器 v2（a-stock-operator-v2）

自包含的 A 股报告生成器，公开财经 API 直采，一条命令完成「采集 → 15 项健康检查 → 模型 → 报告」全流程。输出两份 **Markdown 报告**（红涨绿跌、结论前置、带日期）：**行情复盘报告**与**个股诊断报告**，并内置**次日轮动主线推荐**与**自学习闭环**持续优化模型。

## 核心能力

### 行情分析模式
- **市场全景**：核心指数 / 涨停·炸板·跌停池 / 连板梯队 / 涨跌家数 / 主线题材 / 重点政策消息 / 热点可持续板块。
- **情绪温度计（Model 04）**：温度 + 风险双维量化，判定 冰点/启动/发酵/高潮/分歧 五阶段（分歧阈值随温度滑动），输出 0~10 成仓位区间建议。
- **主线题材（Model 01 + Model 02）**：动态热点发现引擎（五因子：涨停家数/主力净流入/板块涨幅/连板高度/扩散度）实时聚类，不写死题材词典；配合题材生命周期定位标注 萌芽/启动/发酵/高潮/退潮。
- **板块轮动专题**：近一月轮动矩阵（日期列头 × 每日 Top7 板块）+ 资金轮动四象限（Model 03，主线/接力/脉冲/退潮）+ 板块多因子趋势榜（Model 06，15日涨幅+5日动量+资金持续+涨停持续）。
- **次日轮动主线推荐（强化自学习）**：融合「位置(趋势)/资金/强度(趋势内涨停 Z 分)/热度(扩散度)」**四维**打分，输出 主线/接力/潜伏 三层推荐 + 依据 + 风险提示。

### 个股诊断模式
单只个股六维诊断（综合评分 / SWOT / 估值分情景 / 龙虎榜席位 / 筹码与股东结构 / 关键价位）+ 最终诊断操作建议（环形评分 + 关键价位 + 操作策略 3 卡 + 避坑提示）。

## 快速开始

```bash
cd <你的工作目录>   # 数据与报告落在这里，不写回技能目录
py312 scripts/collect_all.py                    # 一键：采集 → 健康检查 → 模型 → 报告
py312 scripts/collect_all.py --only-check       # 仅健康检查（诊断数据缺失/过期）
py312 scripts/collect_all.py --no-models        # 只采集+检查，不跑模型和报告
py312 scripts/collect_all.py --skip collect_news.py  # 跳过指定步骤
```

> 采集脚本依赖 `requests`，请用已装 requests 的 Python 3.12+ 解释器（`py312`）；生成脚本无此依赖。
> 默认**全量重采**，模型与报告仅在数据校验全过后执行，杜绝陈旧报告。`--date YYYYMMDD` 可覆盖目标交易日。

## 产物落点

过程数据**全部外置**、不落技能安装目录：

| 变量 | 缺省 | 作用 |
| --- | --- | --- |
| `A_STOCK_WORK` | `<cwd>/a-stock-operator-v2` | 运行时数据根目录（`data/*.json`、`rotation_history.csv`、`rotation_params.json` 等） |
| `A_STOCK_OUT` | `<cwd>` | 报告输出目录 |

报告（Markdown，带日期）输出到会话工程根目录，如 `行情复盘-2026-09-03.md`、`{name}_个股诊断-2026-09-03.md`、`次日轮动主线推荐-2026-09-03.md`。

## 自学习闭环

每次运行 `collect_all` 生成报告后**自动触发**（无需额外定时任务）：

1. `recommend_rotation` 落盘当日真实**因子快照**（position/fund/strength/heat）+ 封板率环境。
2. `rotation_verify` 批量回填所有「T+3 已可判定」推荐的真实 T+1/T+2/T+3 涨幅，累计 `rotation_history.csv`（携带因子快照）。
3. `rotation_evolve` 直读快照做 Spearman 秩相关反推四维权重、EMA 平滑后回写 `rotation_params.json`；`recommend_rotation` 下次自动加载覆盖内置先验（样本 <20 维持先验）。

### 轮动打分因子（四维）

| 因子 | 含义 | 内置先验权重 |
| --- | --- | --- |
| position | 板块趋势（5 日涨幅趋势分） | 0.48 |
| heat | 扩散度（子题材扩散） | 0.35 |
| fund | 资金持续性（近 5 日为正占比） | 0.08 |
| strength | 趋势内强度（当日涨停家数相对近 5 日均值 Z 分） | 0.09 |

`emotion`（市场级封板率）因对全板块同值、无截面区分，已移出逐板块打分，改由 `recommend_rotation` 做**风控门控**（封板率 <25% 收缩至仅存主线、<40% 减半）。

## 数据源

| 数据 | 来源 |
| --- | --- |
| 指数/涨停池/炸板池/跌停池/热因 | 东方财富公开接口 |
| 涨跌幅榜/行业板块/主力资金 | 东方财富 + 新浪 |
| 快讯（政策/消息） | 东方财富快讯 |
| 板块近 15 日涨幅 | 东方财富（失败兜底同花顺板块指数） |
| 涨停板块计数 | 东方财富涨停池按板块关键词匹配 |

联网采集可能遇 429/断连/东财 IP 风控（约 20 小时自动解除）。失败不污染数据：空结果不落盘、失败项沿用旧值、关键项缺失 `exit 1`。

## 合规

报告末尾固定声明：「以上基于公开行情整理，仅供复盘参考，不构成投资建议。」
