# 🎯 战略顾问技能 (Strategic Advisor)

> **从"指挥AI"到"与AI共创"的全新交互模式**

## 🌟 核心价值

战略顾问技能将AI从传统的"听指挥工具人"转变为"主动思考的战略顾问"，通过**七步深度对话流程**，帮助你将模糊想法转化为清晰的战略调研报告和可执行行动计划。

### 💡 为什么需要这个技能？

- **🤔 想法模糊**：你有想法但不知道从哪开始
- **🎯 方向不明**：面临复杂选择，难以决策
- **🚧 路径不清**：知道目标但不知道怎么实现
- **⚠️ 风险未知**：预见不到潜在的问题和挑战
- **⏰ 资源有限**：不清楚需要什么资源投入

## 🚀 核心特色

### 1. 🎭 角色互换模式
- **传统模式**：你问AI答 → AI执行工具
- **新模式**：AI问你答 → 共同深度思考

### 2. 🧅 五层渐进式提问
1. **🔍 现状探查** - 了解你的真实处境
2. **🔬 问题拆解** - 找到真正要解决的问题
3. **🎯 目标对齐** - 明确成功标准和优先级
4. **🛤️ 路径发现** - 找到可行的实现方法
5. **🛡️ 风险识别** - 预见障碍和应对措施

### 3. 📊 双文件输出
- **📋 战略调研报告** - 深度分析+战略建议
- **🛠️ 行动计划** - 详细实施+可执行清单

### 4. ✅ 七步质量保证
- 第一步：角色声明 → 建立正确期望
- 第二步：五层对话 → 收集完整信息
- 第三步：信息整合 → 生成关键洞察
- 第四步：生成报告 → 结构化输出
- 第五步：制定计划 → 可执行方案
- 第六步：移交选择 → 角色转换
- 第七步：整体审查 → 质量验证

## 📖 使用指南

### 快速开始
```
直接说："战略顾问，帮我思考[你的问题或想法]"
```

### 第一次使用？
1. 直接说你的想法或问题
2. 我会通过一系列问题帮你理清楚
3. 大概需要20-40分钟（包含最终审查）
4. 最后得到两份文档：调研报告+行动计划
5. 我会对整个流程进行逻辑严谨性和可执行性审查

### 使用场景
- 🏗️ **项目规划** - 新项目启动、产品迭代规划
- 🎯 **决策支持** - 方案选择、资源配置决策
- 🔧 **问题解决** - 复杂问题诊断、解决方案设计
- 📈 **目标设定** - 个人发展、职业规划
- 💡 **战略思考** - 商业分析、模式设计

## 📋 输出结果

### 文件格式
- **格式**：标准Markdown (.md)
- **图标**：1-3级标题前增加合适的图标
- **位置**：当前会话根目录 (`<cwd>`)
- **命名**：`{主题}-战略调研报告-{YYYY-MM-DD}.md` 和 `{主题}-行动计划-{YYYY-MM-DD}.md`

### 调研报告结构
```markdown
# 📊 {主题}战略调研报告
## 🔍 一、现在的状况
## 🎯 二、目标是什么
## 💡 三、重要发现
## 🚀 四、战略建议
## ✅ 五、下一步怎么做
```

### 行动计划结构
```markdown
# 🛠️ {主题}行动计划
## 📅 分步实施计划
## 📋 具体行动清单
## 🏆 成功的标准
## 🎒 需要的资源
## 🛡️ 风险应对
```

## 🔧 技术特点

### 零依赖架构
- **无需脚本**：纯规范型技能，完全使用内置工具
- **无需联网**：全靠对话分析，保证隐私性
- **无需配置**：即插即用，无需额外设置

### 工具集成
- **AskUserQuestion** - 深度对话提问
- **TodoWrite** - 流程进度管理
- **Write** - 文件生成输出
- **Read** - 文件审查验证
- **NotifyUser** - 结果展示通知

### 质量保证机制
- **6个审查维度**：逻辑严谨性、报告可执行性、计划可操作性、格式规范性、整体质量、最终结论
- **多层检查点**：每个步骤后都有质量验证
- **标准化输出**：统一的格式和质量标准

## 💡 使用技巧

### 简化流程
如果觉得流程太复杂，可以告诉我"简化一些"，我会：
- 减少提问层次
- 直接给出建议
- 确保质量不被降低

### 异常处理
- **🤷 不知道怎么回答**：告诉我你的真实想法，哪怕不完整
- **⏭️ 想跳过某些问题**：直接说，我们可以跳过
- **🔄 想重新开始**：随时告诉我，我们可以重新来过

### 对话技巧
- **📝 回答越详细**：分析质量越高
- **🎯 聚焦核心问题**：避免偏离主题
- **💡 大胆表达想法**：不要担心想法不够成熟
- **🤔 深入思考**：充分挖掘自己的需求
