# A股一阳指战法量化扫描（a-stock-yiyangzhi）

自包含的 A 股「一阳指战法」量化技能，依据《01_一阳指转势战法》《02_一阳指开门战法》逻辑模型实现。全市场扫描当日涨幅 **≥5%（无上限，涨停/连板均纳入）** 且符合「转势」「开门」形态的个股，输出 **Markdown 报告 + CSV + JSON**，并内置**自学习闭环**持续优化模型。

## 核心策略

| 战法 | 规则 | 说明 |
| --- | --- | --- |
| 一阳指·转势 | 大阳 ≥5%（或双阳确认）+ 站上 MA6 + MA6 走平/向上 + 资金线（量比 ≥1.0，过滤缩量反弹）+ 底部结构（横盘洗盘 / 低位 V 转 / 收盘上穿 MA21 三者取一） | 专注底部反转的 5% 大阳；涨停股交「开门」判定 |
| 一阳指·开门 | 大阳（最好涨停，或近 10 日涨停后当日续攻 +3% 突破前高）+ 价站三线 + 至少两线向上 + 突破近 20 日高 97%（或创近 3 日新高）+ 量能确认 | 捕获突破/涨停/续攻形态 |

两者均**剔除 ST/ST\***（其 5% 涨跌停会干扰筛选）。

## 打分与推荐档位

- 打分 0~100，**已修正「评分倒挂」**（v1.3.0，据 90 交易日收益回放）：原打分把「爆量/涨停/大涨」越打越高，但回测显示这类信号 T+5 转负。现改为**温和放量（量比 1~2.5）最优、爆量/信号日涨停/高位大涨追高降分**，让评分正向对齐「上涨持续性」而非「追高强度」。
- **推荐档位**（排序不再只按评分）：**首选**（转势·非涨停·温和放量大阳）> **关注**（转势涨停 / 开门非涨停）> **追高风险**（开门涨停 / 高位追涨）。实证组合「转势·非涨停·温和 5-10%」T+5 +3.08%，约为全量 8 倍。
- **主线标签**：结合市场情绪温度计与当日热点板块，对候选打「热点 / 中期主线 / 边缘偶发」标签，自动剔除边缘偶发股（公司公告、冷门题材）。

## 卖出纪律（默认建议）

止盈 **+8%** / 止损 **-3%** / 高浮盈回撤 **3%** 移动止盈。90 日回测把全量 T+5 收益从 +0.28% 提到 +0.88%，是当前最大可提升空间（会选、更要会卖）。

## 目录结构

```
a-stock-yiyangzhi/
├── SKILL.md                    # 技能元数据与完整说明
├── README.md                   # 本文件
└── scripts/
    ├── _common.py              # 路径解析 / 常量参数 / 档位函数 / 卖出纪律 / 交易日
    ├── indicators.py           # 转势/开门判定 + 打分 + 卖点监控（内置合成数据自测）
    ├── scan.py                 # 全市场扫描编排（并发抓K线 → 判定 → CSV+JSON → 报告）
    ├── judge.py                # 个股单查
    ├── theme_filter.py         # 主线标签 / 热点板块 / 边缘偶发剔除
    ├── market_emotion.py       # 市场情绪温度计（涨停/跌停/连板/炸板 + 情绪周期）
    ├── optimize.py             # 模型可靠性回放 + 量比阈值校准（回写 params_best.json）
    ├── verify.py               # 历史推荐验证（T+1/T+3/T+5 真实收益回填）
    ├── selflearn.py            # 自学习闭环（验证→重校准→收益回放诊断 + 退出纪律模拟）
    ├── analyze_samples.py      # 人工标注样例校验（F1）
    └── run.py                  # 统一入口（scan/judge/optimize/verify/selflearn）
```

## 快速开始

```bash
cd <本技能目录>
python scripts/run.py scan                # 全市场扫描（默认最近交易日）
python scripts/run.py scan --live         # 盘中扫描
python scripts/run.py scan --no-selflearn # 仅扫描，跳过自学习闭环
python scripts/run.py judge 002491        # 个股单查
python scripts/run.py optimize --top 60   # 模型可靠性 + 阈值优化
python scripts/run.py verify              # 历史推荐验证
python scripts/run.py selflearn           # 自学习闭环
```

> 脚本会按「当前解释器 → `python` → `py`」顺序自动探测解释器；`scripts/run.py` 内相对路径已按脚本自身位置解析，从任意目录 `python <技能绝对路径>/scripts/run.py ...` 亦可。

环境变量（均可选）：

| 变量 | 缺省 | 作用 |
| --- | --- | --- |
| `YZ_RUNTIME` | `<cwd>/a-stock-yiyangzhi` | 运行时数据根目录（采集缓存/筛选结果/验证样本/自学习历史/模型参数） |
| `YZ_OUT` | `<cwd>` | 报告输出目录 |

过程数据**全部外置**、不落技能安装目录；报告（Markdown，带日期）输出到会话工程根目录。

## 自学习闭环

每次运行 `scan` 生成报告后**默认自动触发** `selflearn`（`--no-selflearn` 关闭）：

1. `verify` 用实际 K 线回填已出信号标的的真实 T+1/T+3/T+5 收盘/最高涨幅与涨停，累计 `verify_history.csv`，输出收益口径统计（按战法/档位/评分档分层）。
2. `optimize` 按命中率重校准量比阈值（缓存态），回写 `params_best.json`，下次 scan/judge 自动加载覆盖常量。
3. 收益回放诊断（**口径B·实战**：信号日收盘选出 → T+1 开盘买入，剔除一字板），输出 `一阳指自学习-YYYY-MM-DD.md` 并累计 `selflearn_history.json`，检测「评分倒挂」，并对比「持有到 T+5 vs 8%止盈/3%止损纪律」收益。

## 数据源

| 数据 | 来源 |
| --- | --- |
| 实时候选（涨幅 ≥5% 无上限） | 东方财富 `push2` 榜单 |
| 个股日 K 线（前复权） | 腾讯 K 线接口（增量缓存 `data/kline_cache/`） |
| 行业/概念/热点 | 东方财富公开接口 |

实时候选源偶发被拒时**自动降级**为「日K缓存兜底」，故建议先跑一次扫描累积缓存。
