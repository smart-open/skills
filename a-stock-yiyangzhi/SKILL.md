# a-stock-yiyangzhi · 一阳指转势/开门量化

自包含的 A 股「一阳指战法」量化技能。
依据《01_一阳指转势战法》《02_一阳指开门战法》逻辑模型实现。

## 能力
- **全市场扫描**：每天（盘后或盘中 `--live`）识别当日涨幅约 5%（默认 3%~8% 带）且符合「一阳指·转势」「一阳指·开门」的个股，输出 **Markdown 报告 + CSV + JSON**（含逐只原因、买点、止损、卖点监控）。并识别当日市场热点板块，对每只候选打「热点 / 中期主线 / 边缘偶发」主线标签，**自动剔除边缘偶发股**（如公司公告、冷门题材），保留市场热点、中长期主线与超跌板块个股。
- **个股单查**：输入股票代码或名称 + 日期，逐条判定是否符合两种战法，给出理由与买卖点/止损。
- **模型可靠性 + 阈值优化**：对历史日K逐日回放，统计信号触发后 T+5 涨幅≥5% 的历史命中率，并按命中率校准量比阈值，输出 Markdown 可靠性报告。

## 环境
- Python 3.12+，依赖 `numpy`、`requests`（任意 Python 3.12+ 解释器，如 `python` / `python3` / `py`，需已预装 numpy/requests）。
- 首次使用判断解释器（脚本会按当前解释器 → `python` → `py` 顺序自动探测，一般无需手动指定）：
  - 系统 `python` / `python3`
  - 或 Windows `py`
- 网络无需配置代理 env，脚本内置请求头与重试；实时候选源(push2)偶发被拒时**自动降级**为「日K缓存兜底」，故建议先跑一次扫描累积缓存。

## 判定口径
- 以目标日**收盘**为准；`--live` 为盘中进行中K线，标注“待收盘复核”。
- 候选涨幅带默认 3%~8%（聚焦『约5%大阳』）；**剔除 ST/*ST**（其 5% 涨跌停会干扰筛选）。
- **转势**：大阳≥5% **或双阳确认(前日≈涨停+当日续阳≥4%)** + 站上短均线(MA6) + MA6走平/向上 + **资金线=当日量≥20日均量(量比≥1.0，过滤缩量反弹)** + 底部结构（横盘洗盘 **或** 低位V转 **或** 收盘上穿21日线，三者取一作反例E确认）+ MA21结构通关（收盘上穿21日线/走平/向上/深超跌V转豁免），非高位反例。<br>说明：MA21 **不作为硬门槛**——早段反转MA21仍下行属常态，改以「上穿/走平/深超跌V转」三者取一作为结构确认；资金/量能是否够大是转势的核心门槛。
- **开门**：大阳(最好涨停，**或** 近10日内涨停后当日续攻+3%突破前高的续攻开门) + 价站三线 + 至少两线向上 + 突破近期前高(近20日高97%） **或** 创近3日新高 + 量能确认（常规放量量比≥1.1，**或** 地量洗盘后缩量涨停/一字惜售启动，**或** 续攻开门量比≥0.9）。
- 打分 0~100；题材/情绪为可选增强（后续外接），当前为纯K线量价口径。
